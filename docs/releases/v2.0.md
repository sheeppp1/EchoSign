# HDUSign v2.0

课堂页更新为 Notion 风格的课程工作区：选择课程后直接查看课程信息、实时转写与签到码，保留本地识别、直播预约、通知和签到辅助功能。

## 更新内容

- **以课程为中心的页面**：侧栏按「工作区 / 课程库」组织；标题和面包屑同步显示课程名，时间、教师与教室集中在副标题。压缩顶部属性区，为实时转写留出更多空间。
- **就近操作**：监控和预约按钮移到课程标题旁；切到设置或向下滚动时，顶部仍可停止监控或取消预约。账号设置直接从侧栏「设置」进入。
- **更清楚的签到码**：使用一组保留前导零的等宽数字，支持一键复制。等待识别时显示灰色提示，识别后使用柔和的黄色高亮；活动记录默认折叠并显示条数。
- **统一深浅外观**：直播页与设置页共享正文宽度和对齐规则，提高辅助文字对比度，统一属性行、按钮与开关样式。长课程名自动换行，面包屑过长时省略。
- **明确的课程状态**：区分尚未读取、暂无课程、未选课和加载失败；失败时直接显示原因，提供重试及账号设置入口。后台音频未选择课程时，不再允许直接点击开始监控。
- **布局修正**：修复高 DPI 下课程图标异常放大及列表高度绑定问题，窄窗口保持课程导航和主操作可用。

## 下载与升级

下载 `HDUSign-v2.0-win64.zip`，完整解压后运行 `HDUSign.exe`。支持 Windows 10 / 11 x64，内置 Python 运行环境、浏览器、识别模型与音频组件。

升级前关闭旧版，将新版解压到新目录。需要保留设置和登录态时，按 [升级说明](https://github.com/ys317/EchoSign#升级) 复制个人配置及会话文件，并保留新版的 exe、`_internal/` 和 `models/`。

预约期间需要保持软件运行。平台登录失效或提示无权限时，请在设置中重新登录并核对课程权限。发行包同时提供 `SHA256SUMS.txt` 和所用 FFmpeg 组件的对应源码归档。
